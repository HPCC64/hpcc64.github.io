# HPCC64 Lab

Source for https://lab.hpcc64.com/ — Human–AI research, engineering and publicly inspectable work.

Static HTML and local CSS; no build or application dependencies. GitHub Pages artifact: `public/`. The root-to-Actions cutover requires separate authorization before merge.
Open `public/index.html` directly, or preview: `python3 -m http.server 8000 --directory public` (custom 404 requires host fallback handling).

Use a reviewed PR. Content acceptance and publication need separate owner approval.
See [release instructions](PILOT-RELEASE.md) and [maintenance rules](AGENTS.md).
