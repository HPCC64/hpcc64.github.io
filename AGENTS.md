# Site maintenance

- Publish only `public/`; keep semantic, accessible HTML and local CSS with no unnecessary runtime dependencies.
- Preserve HPCC64 identity, truthful public claims, the site's purpose and separation from the other HPCC64 sites. Do not disclose unapproved material.
- Check links, metadata, 404 handling, responsive layout and keyboard access before release.
- Follow HPCC64 repository review rules. Production publication, hosting configuration and analytics changes require explicit authorization.
