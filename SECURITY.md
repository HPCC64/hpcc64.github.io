# Security

This repository contains a public source project for the static HPCC64 website. Only files in `public/` are intended for web publication.

Do not commit credentials, tokens, private keys, client data or unpublished personal/research material. Treat every file in `public/` as publicly accessible, regardless of repository visibility.

Report suspected vulnerabilities or accidental exposure privately to `inbox@hpcc64.com`; do not post secrets or sensitive details in public issues. Revoke exposed credentials and remove sensitive content from the publication surface; deleting a Git commit does not undo exposure.

Security fixes follow a reviewed pull request, with production changes separately authorized.
